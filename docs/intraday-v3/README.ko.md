# Market Forge Intraday V3 (experimental LIVE WATCH, no orders)

- **Separate from DAY and Swing**: 150 configured tickers, native IEX 5m candles, no synthetic bars, no paid Bigdata API calls, no option liquidity verification.
- Vercel Pro native cron invokes authenticated `GET /scanner/intraday-v3/worker` every 5 minutes with `CRON_SECRET`. UTC schedule 14:02..20:57 on weekdays covers US RTH from 08:00 to 13:55 MT across daylight-saving regimes. Runtime checks actual America/Denver hour, exchange calendar, 09:30–16:00 ET session, and completed candles. Timeliness is best effort, not guaranteed.
- Scans 150 native IEX 5m data since the RTH open, with strict numeric OHLCV, 3 recent contiguous bars, freshness max 10m, at least 6 observed bars, IEX notional >= USD 500k. These heuristics are unvalidated, do not certify consolidated liquidity or options spreads.
- Tiered continuous score 0–100: trend, VWAP, momentum, SPY relative change, IEX volume acceleration, current price range position, IEX liquidity. 55+ with no high chase risk eligible. Top **10 bullish / 10 bearish**, not forcibly filled. Missing SPY movement removes comparative points and is marked as such, not invented. No Bigdata charges.
- First hour compares to `preopen-watch-v1:{day}:report.prior_rth_context.selected` (or V1 verified candidates). Subsequent hours compare to prior **notified** hourly list. States: CONTINUE, NEW, FLIP; removals: WEAKNESS, CHASE, DATA_UNAVAILABLE, REMOVE, FLIP_WATCH. Flip is not a new trade; reverse direction must independently qualify.
- First successful 5m sample in each 08..13 MT hour queues one Telegram summary, expiring after 15m. Outbox idempotency and at-most-once Telegram send, no retry of uncertain attempts. `sent` means Telegram API accepted, not handset receipt.
- Admin dashboard `/intraday-v3`: uses existing private Chart News/TradingView webhook key through POST, to read current data, hourly history, outbox status, and manually request today's sample. Do not paste a secret in chat. POST manual run is idempotent per 5m cutoff.
- Today **2026-11-10**, installation only takes effect after merge and production deployment. It cannot replay what was received at 8am before deployment; post-release first available run records current **as-of** data and compares to the stored 7:20 list. Previous bars are obtained retrospectively and do not imply historical live alerts.
- Bigdata API key exists in project but **no new chargeable calls** are made by V3. User can approve separately after fee/rate budget and verification design. Future official IV and options volume checks are not yet implemented.

**Validation**: CI: tests/test_intraday_v3.py and test_preopen*.py. After production release check deployment SHA/READY, cron registration, first authenticated run/outbox, Telegram delivery state, data errors, and 9:00+ MT reports. Do not claim Telegram delivered before corresponding runtime evidence.
